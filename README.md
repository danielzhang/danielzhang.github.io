# 张德品 · 个人简历

简约科技风的个人简历网站，使用纯 HTML、CSS 和 JavaScript 构建。

## 本地预览

直接打开 `index.html`，或运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署

该仓库已适用于 GitHub Pages。在仓库的 **Settings → Pages** 中，将部署来源选择为：

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

对于 `danielzhang.github.io` 仓库，保存后通常可通过以下地址访问：

https://danielzhang.github.io/
